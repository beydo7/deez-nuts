# Deez Nuts!

Ein Incremental über das Knacken von Nüssen. Du fängst mit bloßen Händen und einer Walnuss an und arbeitest dich über Nussknacker, Hammer und hydraulische Presse bis zur industriellen Nuss-Vernichtung hoch. Ganz gebliebene Kernhälften bringen am meisten, Bruch fast nichts, und die Eichhörnchen, die du für dich arbeiten lässt, klauen mit.

**Status:** Konzeptphase. Engine ist noch nicht entschieden.

## Ordnerstruktur

```
Deez Nuts\
  Bilder\        ← Referenzen, Screenshots, Steam-Bilder (nicht im Repo)

    docs\konzept.md
```

## Loslegen

```bash
git clone https://github.com/beydo7/deez-nuts.git
```

Das Spielkonzept steht in [`docs/konzept.md`](docs/konzept.md), dort sind auch die offenen Entscheidungen gesammelt.

Sobald die Engine feststeht:
1. Projekt in diesem Ordner anlegen.
2. Engine-Abschnitt in `.gitignore` ergänzen (Vorlagen: https://github.com/github/gitignore).
3. Start-Datei (`Spiel_starten.bat`) und diese README anpassen.
